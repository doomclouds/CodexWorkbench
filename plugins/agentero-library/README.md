# 文献库

**0.3.1** · 在 Codex 当前对话的 MCP App 标签页中管理本地 PDF，阅读、批注、翻译并维护 Markdown 研究笔记。界面跟随宿主明暗主题；文献与笔记能力复用用户安装的 Agentero CLI／MCP，内容保留在 Agentero Vault 中。

## 安装

先准备以下本机环境：

- Node.js 24。
- Agentero CLI **v0.15.2**，当前支持的版本。安装方式见 [对应版本的 CLI 说明](https://github.com/poco-ai/Agentero/blob/v0.15.2/docs/backend/cli.md)，平台文件见 [v0.15.2 官方发布页](https://github.com/poco-ai/Agentero/releases/tag/v0.15.2)。CLI 由用户安装，插件不捆绑 Agentero 桌面端或自动安装 CLI。
- 可选的后台 PDF 解析与文字提取需要 CLI 能加载对应平台、架构的原生 **PDFium**。基础阅读、文字选择、查找及批注使用 PDF.js，不要求先配置 PDFium。普通状态检查不会执行诊断文献导入或解析；在配置页点击“保存并检测”才检测原生解析，并保存检测结果供其他实例读取。
- PDF.js 解析使用独立 Worker。宿主不允许启动 Worker 时显示可操作提示，允许你明确点击“用系统查看器打开”，不静默改用界面线程解析。系统查看器显示原始文件；如需带上插件批注，请先导出带批注 PDF。
- 使用系统文件选择器需要在交互式桌面会话运行。Windows 使用系统 PowerShell／文件对话框，macOS 使用系统 `osascript`；不需要另装文件选择器运行库。

在 Codex 的插件目录添加远程商城来源：

```text
https://github.com/doomclouds/CodexWorkbench
```

从 `CodexWorkbench` 商城安装“文献库”。仓库包含插件所需的预构建运行文件，无需下载 ZIP、克隆源码或运行 pnpm 构建。

已安装可用的 Codex CLI 时，也可以使用：

```sh
codex plugin marketplace add doomclouds/CodexWorkbench --ref main
codex plugin add agentero-library@codex-workbench
```

目标平台为 **Windows x64** 与 **macOS arm64**（Apple Silicon，含 M4）。普通界面与业务使用同一套实现；macOS 尚未完成实机验收。具体 Codex 桌面版本及平台能力以安装后的诊断和实际运行结果为准。

## 首次配置

1. 在插件设置或 App 左侧栏底部打开“配置与诊断”，通过选择器定位已安装的 Agentero CLI；也可填写完整路径或 PATH 中可用的命令名。
2. 选择已有 Vault，或填写新位置并点击“创建知识库…”。默认路径为 `~/.codexworkbench/agentero-library/vault`，新建前会显示具体位置供确认。
3. 如需后台解析，选择已安装的 PDFium 目录。点击“保存并检测”，分别确认 CLI、知识库、笔记读写和 PDF 解析状态。
4. 在当前对话打开“文献库”，点击“导入 PDF”并通过系统选择器选择一个或多个文件。默认跳过联网元数据识别，按文件名导入；导入和正文解析是独立任务。
5. 如需翻译，在“选区与全文翻译”中选择 Agentero 文本翻译，或填写 OpenAI 兼容模型服务的地址、模型、目标语言及所需凭据。后台翻译使用独立配置，不复用 Codex 登录态。

CLI 由用户安装和升级。插件保存可执行文件路径，不修改全局 PATH，不复制或迁移已有 Vault，也不自动安装原生 PDFium。文件、目录与导出位置优先使用系统选择器，取消选择会保留原值。CLI、Vault 和 PDFium 路径也可直接填写，PDF 导入另有手动路径备用。

## 使用

文献页以本地 PDF 为默认工作流。

左侧栏集中放置文献、阅读、笔记及阅读工具，可随时收起为图标栏。阅读区顶部只保留文件名与导出等操作；侧栏收起后，分页与缩放通过悬浮控制条操作。目录、批注和论文笔记按需打开，页边备注默认关闭。收起论文笔记会保留草稿与保存队列。

| 页面 | 当前功能 |
| --- | --- |
| 文献 | 多文件 PDF 导入；按标题、作者、年份、标签筛选与排序；分页、阅读状态、标签颜色、BibTeX 导入／导出、补下载资源、移入 Vault 回收站 |
| 阅读 | 连续滚动、物理页跳转、缩放与适宽、旋转、文字查找、目录与书签、内部链接、空格／中键拖动、白色／深色纸张、阅读位置保存 |
| 批注 | 文字高亮／下划线、多色标记、选区备注、区域截图备注、批注筛选与跳转、修改／删除／回复、页边备注卡；导出带批注 PDF、Markdown 或 JSON |
| 翻译与提问 | 选区翻译浮卡与固定译文；逐页、逐段全文译文叠层；将选区、来源与问题发送到所属 Codex 对话 |
| 笔记 | 阅读器侧栏论文笔记及独立笔记页；富文本编辑、Markdown 源码／预览、格式工具栏、代码高亮、公式、表格、任务列表、查找替换、图片附件、双链／反向链接、新建与重命名 |
| 回收站 | 左侧栏底部进入；查看已删除项目的标题、原位置、删除时间；显式用系统查看器打开 PDF 或所在删除批次目录 |

修改 PDF 目录书签会写回当前 PDF。高亮与备注通常保存在 Vault 的论文关联文件中；“导出带批注 PDF”会另存文件，不自动覆盖源 PDF。

笔记停顿后自动保存，切换目标前会提交当前草稿。版本冲突时保留草稿，提供磁盘版本比较、复制和明确载入操作。重命名复用 Agentero 的文件移动能力，同步更新库内 wiki 引用。请明确说“保存到笔记”或“更新这篇笔记”来授权 Agent 写入；普通问答不会自动保存讨论或标为已读。

切换 Vault 后，旧对话的资源引用会失效，需重新选择；未保存草稿与运行任务仍属于原来的库，不能静默改绑到同名路径。

插件附带四个工作流：

| 工作流 | 示例请求 |
| --- | --- |
| [连接与设置](skills/library-setup/SKILL.md) | 检查我的文献库连接，说明还缺什么依赖。 |
| [文献检索](skills/literature-search/SKILL.md) | 在已有文献中找与这个问题相关的论文。 |
| [论文阅读](skills/paper-reading/SKILL.md) | 解释这段方法，并给出原文定位。 |
| [研究笔记](skills/research-notes/SKILL.md) | 把本轮讨论整理到阅读笔记，保留引用。 |

## 数据与正文访问

插件配置、阅读状态和恢复草稿默认保存在 `~/.codexworkbench/agentero-library/`；默认 Vault 位于其中的 `vault/`。使用外部 Vault 时，PDF、笔记、附件与批注继续保存在用户选择的库中。Vault 的 `.agentero/catalog.sqlite` 是上游业务数据，不是可以随意清理的插件缓存。

“允许 Agent 读取 PDF 正文”默认关闭，控制 Agent 工具的正文抽取、版面文本及正文搜索。用户主动发送选区或点击翻译时，会按该次操作使用相应文字，不因此开放其他正文给 Agent。PDF 显示、后台正文提取与已有 layout 读取是不同能力。

全文翻译优先使用已有 layout，缺少时从 PDF 文字层提取段落，按进度显示译文；无法拟合的段落保留原文，可停止或重试。翻译会向所选服务发送相应选区／段落，兼容服务配置与凭据保存在本机 `secrets/translation.json`，不写入论文或工具结果。译文叠层用于阅读，目前不导出整篇译文 PDF。

开启导入元数据识别、补下载资源或翻译时会连接对应服务；交给 Codex 的选区、正文或笔记会进入当前对话的模型上下文。本地存储不代表所有处理都离线。

## 限制与故障处理

- “CLI 已连接”只说明基本连接成功，按诊断页分别确认文献、正文和 PDF 原生能力。
- 普通本地 PDF 解析不保证生成 `page_read` 所需的版面数据。缺少 layout 时不会编造章节或页码锚点。
- 阅读器当前会将 PDF 分块读入内存，单文件上限为 256 MiB；特殊字体／CMap 和图片编码仍需更多样本验证。
- 没有可提取文字的扫描 PDF 可显示和添加区域备注，但文字查找、选区与段落翻译需要可用文字层；本版不内置 OCR。
- 遇到笔记版本冲突时保留草稿并重新读取，避免盲目覆盖。插件内的队列和乐观检查不能保证与外部 Agentero／编辑器之间的跨进程原子 CAS。
- Agentero v0.15.2 的 CLI／MCP 未公开回收站恢复接口，本版只读查看回收站，不提供恢复、清空或永久删除。列表按有界快照分页；达到扫描上限或遇到无法读取的清单时会明确提示，显示数量不代表完整回收站总数。
- 关闭面板不等于取消已提交任务；退出服务后的任务不保证自动续跑。取消不会自动回滚已经写入的文献。
- 全文翻译会尽量保留阅读版面，不保证任意复杂排版都能完整重排；无法处理的段落保留原文。云同步与科研表格不属于当前功能范围。
- Windows Codex 已实际验证 PDF 绘制、鼠标选区、高亮／备注／回复、选区消息接收及排队、Markdown／富文本编辑与自动保存。后续宿主稳定性修复使用隔离合成文档验收，不能据此宣称已消除实际宿主的全部挂起原因；macOS 尚未实机验收。
