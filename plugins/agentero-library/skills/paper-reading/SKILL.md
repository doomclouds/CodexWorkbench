# 论文阅读

基于已连接文献库的真实内容回答问题。用户明确选择的文字可直接作为本次证据；需要更多上下文时再读取，不自动获取整篇论文。

## 取证

1. 从选区或明确目标取得 Vault 与论文引用。目标不清楚时用 `paper_list`／`library_search` 找候选，并用 `paper_get` 消歧。
2. 调用 `paper_read` 读取相关物理页或有界文本窗口，按返回的后续位置继续；比较多篇论文时分别取证。
3. 保留实际证据类型：PDF 物理页、已有 layout、抽取文本的路径／行号不能混用。没有页级证据时使用文档定位，不编造页码、段落锚点或坐标。

## 缺少正文或处理能力

- 正文访问关闭时不从其他工具绕过。用户主动“选区提问”只授权本次选中文字，不因此开启其他页或全文读取。
- 没有可用正文时说明当前证据不足。只有用户明确要求解析且 `library_status` 显示具备相应能力时，才调用 `paper_parse`；该操作会生成派生内容，不属于普通只读问答。
- 解析返回任务后用 `operation_get` 等待结果，再调用 `paper_read`。解析失败不等于原始 PDF 已丢失，也不能声称已生成版面数据。

## 回答

围绕用户问题解释，区分论文的陈述、已读原文的证据与自己的推断。引用包括论文标题／引用及真实定位；未取得的实验结果和引用不补写。

打开阅读器、完成解释或浏览多页都不自动标记已读、写笔记、添加标注或更新 metadata。用户明确要求保存讨论时，交给研究笔记工作流。

## 标注、备注与翻译

- 用户明确要求查看标注时用 `mark_list` 按论文、页或关键词取证；区分原文 quote、用户 comment 与回复。返回被截断时收窄范围，不把前100条当作全量。
- 明确要求更新已有批注时先读取其 id/revision，再用 `mark_update`；新增精确标注必须有工具或当前真实选区提供的矩形／页尺寸，不能凭文本猜坐标。没有几何信息时打开阅读器让用户选择，或先查看已有页级证据。
- 用户主动请求翻译时才用 `translate_text`；它通过用户配置的 CLI 或模型服务处理所选文本，不复用 Codex 登录态，不自动把整篇论文发送给外部服务。
- 导出、改书签或删除标注仅按明确任务执行；标注删除不等于删除论文。导出位置由用户选择，不将结果写回原始PDF来冒充另存副本。
