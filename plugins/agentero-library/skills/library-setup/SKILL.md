# 文献库设置

帮助用户把文献插件连接到本机 Agentero 与明确选择的 Vault。使用文献插件的公开 MCP 工具，CLI 由用户安装，不提供原始 CLI 命令或改写用户全局 MCP 配置。

## 工作流

1. 调用 `library_status`，区分 CLI 缺失、版本不支持、Vault 未配置与仅 PDF 处理不可用。已经可用的配置直接使用，不重复引导。
2. 需要配置时调用 `library_open`，使用 `view: "settings"` 打开配置视图；也可引导用户在宿主插件详情点击“配置与诊断”。填写 CLI 路径和 Vault，路径以用户选择为准，不从论文内容或模型猜测位置。
3. 只有用户明确要求新建库时才使用配置页的创建操作；选择已有路径不等于创建或迁移，也不静默覆盖非空目录。
4. 配置保存后再次调用 `library_status`，说明哪些能力已可用、哪些仍需处理。没有 CLI 或 Vault 时也应能够进入配置。

## 能力边界

- CLI 能运行不等于 PDF 原生引擎就绪。缺少原生 PDFium 时保留可用的文献／笔记和浏览器阅读功能，后台解析与文字定位按诊断状态处理。普通状态检查不自动触发导入、解析或耗时的原生诊断。
- 分别说明浏览器显示 PDF、Agent 读取 PDF 文字、已有 `PAPER.md`、layout 与图像证据的可用性；一种可用不证明其余能力可用。没有 OCR 或模型可见页图时，不承诺能理解扫描页、图表或区域截图。
- 不自动安装、下载或升级 Agentero，不修改 PATH，不接管用户独立运行的服务。安装需求引导至插件配置页的官方说明。
- 插件默认数据根目录是 `~/.codexworkbench/agentero-library/`，已有外部 Vault 只保存引用，不搬迁内容。
- 正文读取开关由用户设置。关闭时不尝试通过其他工具绕过；用户主动发送的选区只用于本次请求，不因此开启全文权限。关联笔记仍使用笔记工具，修订 `PAPER.md` 使用专用正文工具。

结束时给出实际状态及必要的下一步，不把打开配置页、版本检查通过或尚在运行的诊断说成全部完成。
