# 文献检索

围绕用户当前问题返回可核验的文献短名单。通过插件公开工具工作，不让模型拼接原始 CLI 参数。

## 本地检索

- 先用 `library_status` 取得当前明确的 Vault 引用；后续调用始终使用该库，不能因全局默认设置变化而改查其他库。
- 列表和元数据筛选使用 `paper_list`，关键词和笔记检索使用 `library_search`。需要摘要或消歧时用 `paper_get` 回读候选，不凭标题编写论文结论。
- 按返回的游标继续读取。遇到 `CURSOR_EXPIRED` 重读第一页；如工具报告扫描或过滤限制，保留该说明，不把截断结果说成完整库。
- 正文范围遵守正文读取开关；没有权限或证据时，使用可用的 metadata 与笔记并说明范围。

## 本地 PDF 导入

- 用户已取消在线发现功能，不调用或建议 `paper_discover`，不自动连接 arXiv 搜索。
- 只有用户明确要求时调用 `paper_import` 导入已指定的本地 PDF，或通过 `library_open` 引导在界面用选择器选择文件；范围限于用户选择的文件。
- 导入返回任务引用后通过 `operation_get` 确认终态。分别报告成功、失败与部分成功；需要取消时只对本插件拥有的任务调用 `operation_cancel`。
- 缺少正文解析能力不等于导入失败；把文件入库、元数据识别和后续解析的实际结果分开说明。

## 已删除的文献

- 用户寻找已删除项目时，通过 `library_open` 的 `view: "trash"` 打开回收站，或使用 `trash_list` 读取当前 Vault 的有界元数据。说明扫描限制，按游标翻页；不把当前快照数量说成完整总数。
- 当前 Agentero v0.15.2 公开 CLI／MCP 不支持恢复，插件仅提供查看与用户点击后打开 PDF／批次目录。不要自行移动回收站文件、修改清单或数据库来模拟恢复，不提供清空或永久删除。

结果优先列标题、实际年份、来源／标识符、库内引用和与问题的关系。引用与页码来自返回的数据，不补造 DOI、下载状态或精确定位。普通检索不写笔记、不标已读、不修改标签。
