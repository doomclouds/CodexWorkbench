# 把任务做深

保持用户原定的目标、范围和交付物。重写前先回答四个问题：

1. 熟悉这个领域的优秀专业人士还会做哪件用户没有点出、却能改善结果的事？
2. 专业人士会从哪些最接近事实的原始材料开始？具体指出可用的材料，例如原始记录、样本或实际作品。
3. 他们会采用哪些具体方法和工具？
4. 除了用户或助手自己的判断，还有什么独立证据能检验结果是否正确？

据此交付一份可直接使用的提示词。如果在原任务范围内做一个小实验就能区分备选方案，而且结果会影响选择，就在提示词中要求执行者做最小实验，并根据观察结果推荐方案。产品取舍和个人偏好中无法由实验决定的部分，留给用户决定。本次交付到改写后的提示词为止。
