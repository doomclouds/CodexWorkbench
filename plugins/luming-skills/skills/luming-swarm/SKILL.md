# 并行派工

1. 明确目标、授权范围和完成标准。把可独立交付且委派有助于节省时间或提高可靠性的工作分给子代理。按各项工作的前置依赖安排启动时间。必须一起决策或落地的改动交给同一个负责人。方案阶段可分派调查和复核，实施按用户授权开始。
2. 给每位子代理一份能独立理解的任务单。写明目标、输入与基线、适用的项目规则、读写范围、验收方式和要带回的证据。核对代码时，标明提交和需要覆盖的工作区差异。并行写入使用独立的 Git worktree 或输出目录。必须共享的文件、构建输出、桌面或设备由一个负责人按顺序操作。
3. 用当前会话的子代理工具启动能同时开展的任务，主代理同时推进手头独立的工作。若子代理工具不可用，按授权完成可做的部分，并说明实际执行方式。
4. 收齐所需结果后按完成标准验收。核对支持结论的原始材料或运行输出，复跑影响结论且可复现的检查。有改动时检查 diff，并在整合后验证受影响的行为。受阻时先定位原因，补做能独立推进的部分。交付一份汇总，说明完成的工作、发现的问题、证据与还未覆盖的范围。
