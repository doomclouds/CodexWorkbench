# 工程流程

1. 识别本轮要交付什么。依据用户的最新要求和已确认的范围，确定当前是看方案、实施还是复核。用户指定了专项技能或交付物时，以该要求为准。
2. 需要确定工程范围、接口或状态归属时，读取 [工程设计](../luming-architect/SKILL.md)。用户要先看方案时，交付方案后等待确认。
3. 已获准实施且关键取舍已定时，按项目约定执行。能独立推进且并行有收益时，读取 [并行派工](../luming-swarm/SKILL.md)，把同一份已确认范围交给子代理。
4. 发现需要扩围时，说明新增改动、必要性和影响，只就变化部分取得确认。交付时，对照已确认方案核对实际 diff、契约和验证结果。
